# claude-starter

Заготовка для новых проектов с Claude Code.

## Что внутри
- `.claude/skills/`: навыки (инженерные Agent Skills, frontend-design, impeccable, graphify, ui-ux-pro-max, humanizer, маркетинг, last30days).
- `.claude/commands/`, `.claude/agents/`, `.claude/references/`: команды `/spec`, `/build`, `/review` и др., агенты-ревьюеры, справочники.
- `.mcp.json`: библиотека промптов prompts.chat.
- `CLAUDE.md`: правила для Claude.
- `docs/`: конспекты.

## Как начать новый проект
1. На странице этого репозитория нажать **Use this template**, затем **Create a new repository**.
2. Дать новому репозиторию имя и создать.
3. Открыть новое окно Claude Code на новом репозитории.
4. Первым сообщением написать, что за проект: Claude заполнит раздел «Текущий проект» в CLAUDE.md.

## Как обновлять
Новые навыки добавлять сюда, а не только в отдельный проект. В уже созданные проекты обновления сами не попадают: их нужно скопировать туда отдельно.
