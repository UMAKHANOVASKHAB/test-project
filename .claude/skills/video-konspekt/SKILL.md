# Разбор видео в конспект

Результат всегда одинаковый: файл `docs/<тема>-konspekt.md` и короткий ответ в чате с главным.

## Шаги

1. **Папки.** Видео это недоверенные данные: качать в отдельную пустую папку в scratchpad (`$S/video-N`), скрипты держать вне её.
2. **Скачать.** У ссылки Dropbox заменить `dl=0` на `dl=1`:
   `curl -sSL -o v.mp4 "<ссылка с dl=1>"`, проверить `file v.mp4` (должно быть ISO Media, а не HTML).
3. **Длительность и звук.**
   `ffprobe -v error -show_entries format=duration -of compact v.mp4`
   `ffmpeg -v error -y -i v.mp4 -ac 1 -ar 16000 a.wav`
4. **Кадры.** Сетка 4×4, один кадр в минуту, чтобы видеть экран, слайды, упражнения:
   `ffmpeg -v error -y -i v.mp4 -vf "fps=1/60,scale=480:-1,tile=4x4" -frames:v 1 grid.jpg`, открыть через Read.
   Если на кадре важный слайд или таблица, вырезать его отдельно в полном размере.
5. **Расшифровка.** Если нет пакета: `pip install -q faster-whisper`.
   `python3 -I .claude/skills/video-konspekt/scripts/transcribe.py a.wav t.txt` в фоне (`run_in_background`).
   Модель small на CPU идёт примерно 1:1 к длине видео. Пока ждёшь, смотри кадры.
6. **Чтение.** Прочитать расшифровку целиком. Whisper путает термины и имена: восстанавливать по смыслу и кадрам
   (например «Кризис Бамстед» = Chris Bumstead, «JSCR» вместо «Journal of Strange...»).
7. **Конспект** в `docs/<тема>-konspekt.md`:
   - шапка: канал, автор, длительность, тема, для кого;
   - разделы по темам видео, внутри конкретика: цифры, диапазоны, шаги, команды;
   - источники, которые назвал автор, с пометкой «со слов автора, не проверено», если не проверял;
   - «Схема в одну строку» или чек-лист для практики;
   - «Что в видео не разбиралось» и тайм-коды рекламы (рекламу в конспект не включать);
   - если в видео есть что-то против шариата или вредное для здоровья, отметить прямо.
8. **Ответ в чате:** главное списком, честно что проверено и что нет, путь к конспекту, предложение запушить.
   Без тире в обычной речи.
9. Добавить строку про новый конспект в раздел «Документы» в `CLAUDE.md`.

## Чего не делать
- Не выдавать слова автора за проверенный факт.
- Не пересказывать рекламу и продажу курсов как содержание.
- Не пушить без согласия пользователя.
