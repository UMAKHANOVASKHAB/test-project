# Конспект: 5 команд Claude Code для экономии лимита и качества

Источник: видео alexandro_ai (Александр Садеков), 51 с, 26.10.2026.
Сверено с документацией Claude Code (26.10.2026): code.claude.com/docs/en/commands, code.claude.com/docs/en/model-config.

## Команды

| № | Команда | Что делает | Когда применять у нас |
|---|---|---|---|
| 1 | `/init` | Создаёт `CLAUDE.md`: правила проекта, которые Claude читает в каждом новом чате | Один раз на новый проект. В `test-project` и `claude-starter` уже есть, новые правила дописываем туда, а не повторяем в каждом чате |
| 2 | Субагенты (`.claude/agents/`) | Отдельный помощник со своими правилами и своим контекстом, основной чат не засоряется | Уже есть: `code-reviewer`, `security-auditor`, `test-engineer`, `web-performance-auditor`. С v2.1.198 команда `/agents` только напоминает: нового агента просим создать словами или кладём файл в `.claude/agents/` |
| 3 | `/compact [на чём сосредоточиться]` | Сжимает длинную переписку в сводку, освобождает контекст и лимит. Можно указать, что сохранить: `/compact оставь решения по оплате и список недоделанного` | Чат стал длинным, а задача та же. Если задача новая, лучше `/clear` (новый пустой чат) |
| 4 | `/rewind` (псевдонимы `/checkpoint`, `/undo`) | Откатывает переписку и/или код к прошлой точке | Claude сделал хуже, чем было: откатить и переформулировать, а не просить «верни как было» (это тратит лимит и не всегда точно) |
| 5 | `ultrathink` в тексте запроса | Глубже думает только на этот ход, общий уровень усилий не меняется | Сложное и рискованное: безопасность, оплата, деньги, поиск причины сбоя. На мелочах не писать, это лишний расход |

Уточнения по документации:
- Слова «think», «think hard» Claude Code не распознаёт как команды, работает только `ultrathink`.
- Постоянный уровень усилий меняется командой `/effort` (`low`, `medium`, `high`, `xhigh`, `max`, `auto`).
- `/context` показывает, чем занят контекст, полезно перед `/compact`.

## Как это применяем в 9 bar coffee

- Новый чат по боту начинается с `CLAUDE.md` и `docs/runbook.md`, повторно объяснять проект не нужно.
- Длинная починка: в середине `/compact` с указанием сохранить найденную причину и что уже проверено.
- Правка сломала мини-апп: `/rewind` до последней рабочей точки. Если изменения уже ушли в main (а значит на Railway), откат делаем через git (`git revert`), `/rewind` не отменяет push.
- Онлайн-оплата и проверка безопасности по `docs/mimic-konspekt.md`: писать `ultrathink`.

Не проверено: есть ли `/rewind` и `/compact` в мобильном приложении Claude так же, как в терминале. Если команда не находится, напишите её словами: «сожми переписку» или «откати последние изменения».
