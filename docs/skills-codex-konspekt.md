# Конспект: навыки (skills) вместо промптов

Источник: видео канала «Нейропросвещение», автор Рома Райт (16:56, файл из Dropbox от 25.10.2026). Показано на Codex, но всё то же самое работает в Claude Code: навыки у них одного формата (папка с `SKILL.md`).
С 11:51 до 13:03 реклама платного курса автора, в конспект не входит.

## 1. Промпт, правила проекта, навык: в чём разница
| Что | Где лежит | Когда работает |
|---|---|---|
| Промпт | одно сообщение | один раз |
| Правила проекта | `AGENTS.md` в Codex, `CLAUDE.md` у нас | добавляются к каждому сообщению в проекте |
| Навык | папка `skills/<имя>/` с `SKILL.md` и файлами | по команде `/имя` или сам, когда задача подходит под описание |

- Навык может содержать сотни промптов по объёму: примеры, шаблоны, вложенные навыки по этапам (у автора навык YouTube включает отдельные навыки для заголовка, обложки и т. д.).
- Пример: в навык для обложек положены хорошие и плохие обложки со статистикой, поэтому агент знает, что работает.

## 2. Что автоматизировать навыком
- Только повторяющиеся задачи, где ты точно знаешь, каким должен быть итог (например, «план для команды на лист А4 из скринкаста»).
- Смысл: результат каждый раз одинаковый, не надо объяснять заново по 30 минут.

## 3. Как навык включается сам
- Агент выбирает навык по полю `description`: там написано, что делает навык и когда его применять.
- Хорошее описание = навык срабатывает без напоминаний. Плюс короткое имя, чтобы вызывать вручную (`/task-creator`).

## 4. Где хранить навыки
- Общие (нужны всегда и везде, например улучшение промптов): в глобальной папке агента (`~/.codex/skills`, у Claude Code `~/.claude/skills`).
- Привязанные к проекту (нужен контекст репозитория, например обложки для YouTube): в `.claude/skills/` проекта.
- Лишних навыков не ставить.

## 5. Как создать свой навык
1. Сначала сделать задачу вручную в диалоге, внести правки, добиться нужного результата.
2. Попросить встроенный навык создания навыков (в Codex `skill-creator`, у нас `anthropic-skills:skill-creator`) оформить этот путь в навык с понятным именем.
3. Проверить `description` и шаги.

## 6. Навыки из интернета
- Автор почти всё делает сам: универсальных навыков не бывает, шаблонный инструмент даёт шаблонный результат.
- Готовыми стоит брать только известные и проверенные, до ~20 штук. Три категории поиска:
  1) продумывание продукта (интервью с пользователями, гипотезы, план реализации);
  2) работа с внешними библиотеками и кодом (документация, видео, PDF);
  3) интеграции с платформами (Vercel, Supabase, Postgres и т. п.).
- Дизайн: frontend-design от Anthropic, Web Design Guidelines, impeccable (Paul Bakaus). Навык дизайна только помощник, вкус он не заменяет.
- Установка пакета навыков: прикрепить папку в диалог и попросить установить для Codex и для Claude.
