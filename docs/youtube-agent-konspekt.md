# YouTube Agent: конспект видео и установка

Источник: короткое видео «Claude сам ведёт твой YouTube канал» (ноябрь 2026). Репозиторий из видео: https://github.com/Jakeschincariol/youtube-agent-skill (MIT, 4,7 тыс. звёзд, версия плагина 1.0.0, коммит a2feb21).

## Что обещает видео и что на самом деле
Видео: «Claude сам ведёт канал». Это преувеличение. Сам автор в README пишет: скиллы ничего не публикуют, они пишут тексты и списки, загружает человек. Каждый скилл заканчивается вопросом «ship it, or change it?» (выкладываем или правим).

## 11 скиллов
| Команда | Что делает |
| --- | --- |
| `/yt-script` | Сценарий из идеи: 5 хуков по 21 формуле, оценка скриптом, лучшие 2, сценарий по битам с пометками [ON SCREEN] |
| `/yt-package` | Название и обложка как одна пара: длина (60/40 символов), повторы, не больше 3 слов на обложке |
| `/yt-edit` | Монтажный лист по субтитрам (srt, vtt, json Whisper): паузы, паразиты, повторные дубли с таймкодами |
| `/yt-comment` | Комментарии в 4 кучи (вопросы, поправки, похвала, провокации), ответы до 30 слов, какой закрепить |
| `/yt-plan` | План недели под ваши часы: 1 главный ролик, 1 лёгкий, 3 Shorts из главного |
| `/yt-viral` | Что работает в нише: ролики, обогнавшие медиану своего же канала (нужно от 4 роликов на канал) |
| `/yt-retention` | Разбор выгрузки удержания из YouTube Studio: утечка на хуке, обрывы, плавный спад |
| `/yt-shorts` | Фрагменты 20–55 с, понятные без всего ролика, новая первая фраза |
| `/yt-seo` | Описание, теги (честно: почти не влияют), 3 поисковых запроса |
| `/yt-chapters` | Главы по субтитрам с проверкой правил YouTube (00:00, от 3 глав, от 10 с) |
| `/yt-audit` | Разбор канала с итогом в ОДНУ главную правку |

## Где лежит
- Скиллы: `.claude/skills/yt-*`, лицензия `.claude/skills/LICENSE-youtube-agent-skill`.
- Шаблон профиля голоса: `.claude/youtube/voice.template.md`. Скопировать в `.claude/youtube/voice.md` и заполнить, или прислать 3 своих ролика (ссылки или субтитры) и попросить «напиши мой voice.md».
- Наша правка: 7 скиллов сначала ищут `.claude/youtube/voice.md` в проекте, потом `~/.claude/youtube/voice.md` (домашняя папка в облачной сессии стирается).

## Проверка при установке
- Прочитаны все 11 SKILL.md и 6 скриптов: только стандартная библиотека Python, нет сети, нет запуска команд, нет чтения паролей и cookies.
- Запущены `hookscore.py`, `title.py`, `deadair.py`: работают.
- Ограничение: формулы хуков и список слов-паразитов на английском. Для русских текстов оценки ориентировочные (русское «эм» как паразит не ловится, только как пауза).

## Рамки
- Хук и цифры: скиллы запрещают выдумывать числа, это совпадает с нашим правилом «без обмана».
- `/yt-viral` предлагает собирать данные через `yt-dlp`. Массовая выгрузка может нарушать условия YouTube, брать только открытые списки и в разумном объёме.
- По шариату: сам инструмент дозволен, ответственность за содержание роликов. Без музыки (по мнению большинства учёных), без харам-рекламы, без кликбейта, который обманывает зрителя (заголовок должен честно обещать то, что есть в ролике).
