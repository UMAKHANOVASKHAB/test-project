# Чек-лист перед выкладкой

Для сайта, Telegram-бота и мобильного приложения. Claude проходит его перед каждым push в main.

## Всегда
- [ ] Тесты, lint и сборка зелёные локально и в GitHub Actions.
- [ ] Новая логика с деньгами, баллами, лимитами покрыта тестом, включая «плохой» ввод.
- [ ] Сервер не доверяет клиенту: цены, роли, id пользователя проверяются на сервере.
- [ ] Двойное нажатие и повтор запроса не создают дубль (ключ идемпотентности, блокировка кнопки).
- [ ] Ошибка сети показывается человеку понятным текстом, данные не теряются.
- [ ] Секретов нет в коде и в истории git.
- [ ] Изменение схемы базы работает и на новой, и на старой базе (миграция).
- [ ] Понятно, как откатиться (Railway → Deployments → Redeploy прошлого).

## Telegram-бот и мини-апп
- [ ] initData проверяется на сервере по подписи, `initDataUnsafe` только для показа.
- [ ] Команды администратора нельзя выполнить постороннему.
- [ ] Один токен бота запущен только в одном месте (иначе 409 Conflict).

## Сайт
- [ ] Работает на iPhone (Safari) и Android, ширина 360 px без горизонтальной прокрутки.
- [ ] HTTPS, правильные заголовки, формы защищены от спама.

## Мобильное приложение
- [ ] Проверено на реальном устройстве, а не только в эмуляторе.
- [ ] Разрешения (камера, геолокация) запрашиваются только когда нужны, с объяснением.
- [ ] Офлайн и слабая сеть не ломают приложение.

## После выкладки
- [ ] Открыть приложение и пройти главный сценарий руками (заказ, оплата и т.п.).
- [ ] Посмотреть логи сервера на ошибки.
