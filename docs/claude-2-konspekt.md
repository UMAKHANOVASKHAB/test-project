# Claude Code 2.0: конспект видео (10 фишек настольного приложения)

Источник: видео пользователя от 01.11.2026, расшифровано whisper. Даты и цены из видео не все проверены, проверенное отмечено.

## Что установлено у нас
- **Защита от удалений** (мод 2 из видео): хук `.claude/hooks/delete-guard.py`, подключён в `.claude/settings.json`. Работает везде, включая облачные сессии. Блокирует `rm -r` вне временных папок (`/tmp`, `node_modules`, `dist`, `build`, `.cache`...), `git clean -f`, `git reset --hard`, `git push --force`, `find -delete`, стирание дисков. Чтобы удалить нужное, Claude спрашивает пользователя.
- **Таймер кэша** (мод 1 из видео): мод `claude-mods/cache-timer`. Полоска над полем ввода: зелёная, пока кэш тёплый, жёлтая после 45 минут, красная после 60 минут с кнопкой «Сжать чат». В настольном приложении включается сам после доверия к папке проекта. В облачной сессии плагины из репозитория не ставятся (документация code.claude.com/docs/en/cloud-environments), поэтому там Claude по просьбе копирует мод в папку модов сессии через навык `plugin-authoring`, а пользователь нажимает «Turn them on».
- **Звук финиша** (мод 3) не ставился: в облачном контейнере звука нет, а на телефон приходят уведомления приложения.

## 10 фишек (встроены в приложение, ставить нечего)
1. **Панель сессии справа**: папка, Remote Control (сессия с компьютера видна на телефоне), карточка контекста (чем занята память: сообщения, навыки, MCP). В настройках Claude Code включить: новые сессии сразу в Remote Control и не давать компьютеру засыпать.
2. **Разделы чатов**: три точки у чата, «Переместить в новый раздел», как папки.
3. **Вложенные сессии**: «Выполни три задачи параллельно и под каждой открой вложенную сессию». В отличие от субагента это живой чат, в него можно зайти и поправить.
4. **Главная сессия**: закрепить чат и написать «Теперь ты главная сессия, следи за всеми остальными». Есть защитный лимит на рассылку по многим чатам (в видео 10 из 12 дошли). Полезный вопрос: «Какие чаты ждут моего решения?».
5. **Claude Code Projects**: то же в облаке Anthropic, работает при закрытом ноутбуке, общая память и доска задач. Файлы уходят на серверы Anthropic. Бета для Pro и Max.
6. **Боковой чат**: Ctrl+; (или команда) задать вопрос, не прерывая основную задачу и не засоряя её историю.
7. **Чаты рядом**: Alt (Option) и клик по чату в левой панели. На практике 2–3 окна.
8. **Офисный пакет в артефактах**: документы (выгрузка в Google Docs), презентации (PowerPoint), дизайн, дашборды (Pro и Max). Claude Motion только Team и Enterprise. По видео сайт Claude Design закрывается 14 декабря (не проверено).
9. **Слэш-команды**: `/skill-doctor` (сколько контекста ест каждый навык и как часто нужен), `/advisor` (дешёвая модель работает, тяжёлая советует), `/insights`, `/recap`, `/output-style`, `/rewind` или двойной Esc (откат), Ctrl+/ (шпаргалка клавиш).
10. **Моды**: менять интерфейс и поведение приложения описанием на русском.

## Прочее из видео
- Режим Cowork встроен в обычный чат, по видео с 10 ноября у всех (не проверено).
- Кэш промпта живёт 60 минут. После часа простоя первое сообщение перечитывает весь чат по полной цене: лучше сжать чат (`/compact`) или начать новый.
- Подписка Max: с 07.10.2026 ежемесячные кредиты на API ($100 на Max 5x, $200 на Max 20x). Работают для API, Agent SDK и Managed Agents, не для обычного Claude Code. Проверено по вторичным источникам (пресса, снимок страницы цен от 15.10.2026), справку Anthropic не нашли.
