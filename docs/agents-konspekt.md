# Конспект: команда ИИ-агентов для поиска клиентов и сайтов

Источник: видео автора Halal Code (01.10.2026, 5 минут). Продолжение `docs/halal-code-konspekt.md`: там как продавать вручную, здесь как переложить рутину на агентов.

## Идея
Вместо того чтобы самому искать клиентов, писать им и делать сайты, человек раздаёт работу агентам и только управляет ими («оркестратор»): проверяет, утверждает, созванивается с клиентом.

## Цепочка из 6 агентов (как в видео)
1. **Scout (разведчик)**: ищет лидов, то есть бизнесы без сайта или со слабым сайтом. Источники: Instagram, карты, Telegram. В видео нашёл 200 лидов по России и СНГ.
2. **Outreach (рассылка)**: под каждого лида пишет личное сообщение по его боли. Пример: барбершоп записывает только через виджет YClients, нет сайта и Telegram, клиенту трудно понять, чем он лучше соседей.
3. Человек: созвон 15–30 минут с теми, кто ответил. Узнать задачу, показать свои работы.
4. **Designer**: делает дизайн, человек утверждает.
5. **Developer**: на самой сильной модели превращает дизайн в живой сайт.
6. **Reviewer**: проверяет весь код (в видео Fable 5.1 или Opus 5.5, по расходу токенов).
7. План автора: агент **утреннего отчёта** (сколько найдено, сколько написано, сколько ответили).

Польза: рутина (поиск, тексты, отчёты) уходит агентам, у человека остаются решения и общение с клиентом.

## Наши правила поверх видео (обязательно)
- **Без массового спама.** Наш же конспект Halal Code (глава 3) предупреждает: рассылка вслепую отвечает единицами и считается спамом. Агент готовит черновики, человек сам читает каждое и отправляет вручную, понемногу (10–20 в день).
- **Только открытые данные бизнеса**: название, публичная страница, рабочий контакт с карточки. Не собирать личные данные людей, не парсить соцсети программами (это нарушает правила Instagram и других площадок).
- **Честный текст**: без выдуманных кейсов, отзывов и цифр. Обман в торговле запрещён.
- **Отказ значит отказ**: если человек не ответил или сказал «нет», больше не пишем.
- **Реклама по SMS, e-mail и звонкам** без согласия получателя запрещена (ст. 18 закона «О рекламе»). Первое сообщение должно быть вопросом и знакомством, а не рекламой.
- Instagram в России признан продуктом экстремистской организации Meta. Самим пользоваться им не запрещено, но рекламу там размещать нельзя. Безопаснее искать через 2ГИС, Яндекс Карты и Telegram.

## Как это устроено у нас
Агенты лежат в `.claude/agents/` и запускаются в Claude Code по имени:
- `scout`: ищет бизнесы и пишет таблицу `leads/leads.md`;
- `outreach`: пишет первые сообщения по формуле из конспекта Halal Code (приветствие, наблюдение, кто ты, вопрос) в `leads/messages.md`;
- `designer`: план дизайна по навыку frontend-design в `projects/<клиент>/design.md`;
- `developer`: делает сайт по утверждённому плану;
- `code-reviewer`, `security-auditor`: проверка перед сдачей (уже были в проекте).
Утренний отчёт можно сделать позже через расписание (Routine) по таблице лидов.
