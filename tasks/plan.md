# План: демо мини-аппа «9 bar coffee»

Цель: к 27.09 показать владельцу рабочий прототип на телефоне. Спецификация в `SPEC.md`.

## Порядок сборки

1. **Фронт без бэка** (главное для демо). Vite + React + TS, Telegram SDK. Три экрана: Меню, Корзина, Штампы. Заказы и штампы хранятся в localStorage через слой `api`, который потом переключится на сервер одной строкой.
2. **Бэк + бот** (когда будет токен). Express + SQLite + grammy. `POST /api/orders` → сообщение в чат кофейни. Подключается заменой `VITE_API_URL`.
3. **Деплой**: фронт на Vercel (статичный), бэк на Railway. Бот получает ссылку на мини-апп через BotFather `/setmenubutton`.

## Компоненты фронта

- `lib/telegram.ts`: инициализация WebApp, имя пользователя, тема, haptic.
- `lib/money.ts`: формат рублей.
- `lib/slots.ts`: слоты самовывоза (чистая функция, тест).
- `lib/loyalty.ts`: подсчёт штампов (чистая функция, тест).
- `lib/api.ts`: интерфейс `createOrder`, `getStamps`; реализация `localApi` (localStorage) и `remoteApi` (fetch).
- `state/cart.ts`: корзина (useReducer + контекст).
- `screens/Menu.tsx`: категории-табы, карточки, выбор размера.
- `screens/Cart.tsx`: состав, слоты, комментарий, кнопка «Заказать» через MainButton Telegram.
- `screens/Loyalty.tsx`: 6 кружков, прогресс, история заказов.
- `components/`: Header, CategoryTabs, ItemCard, VariantPicker, Stamp, BottomNav.

## Риски

- Мини-апп без HTTPS в Telegram не откроется: для показа нужен деплой на Vercel. Запасной вариант: открыть в Safari как обычный сайт, всё работает и без Telegram.
- Фото: используем 3 фото с карточки 2ГИС как обложки категорий, остальное эмодзи-заглушки. Не выдавать за финальный дизайн.
- Бот: до получения токена заказ «отправляется» локально и показывается экран подтверждения.

## Проверка перед показом

- `npm test` зелёный (слоты, лояльность, корзина).
- `npm run build` без ошибок.
- Ручной прогон на iPhone: меню → 2 позиции → время → заказать → штамп +1.
