# Папка intent

Здесь лежит «намерение» каждой новой функции, сайта, бота или приложения: что нужно и зачем.
Это первое звено цепочки: intent → спецификация → план → код.

## Как появляется intent
1. Claude расспрашивает владельца по одному вопросу (навык `interview-me`), пока не поймёт задачу почти полностью.
2. Записывает итог в `intent/<имя>.md` по шаблону `_template.md`.
3. Владелец читает, правит и подтверждает. Статус меняется на «подтверждён».
4. Только после этого пишется спецификация и код.

Если по ходу работы выясняется, что intent был понят неверно, сначала правим intent, потом код.
