# Spec: Telegram-мини-апп для кофейни «9 bar coffee»

Статус: черновик для демо, показ владельцу 27.09.2026.

## Objective

**Что строим.** Telegram Mini App для кофейни «9 bar coffee» (Махачкала, ул. Леваневского, 11): меню с фото и ценами, предзаказ на вынос, карта лояльности. Открывается по кнопке в Telegram-боте кофейни.

**Зачем владельцу.** Кофейня продаёт гостей и заказы, не приложение. Три выгоды:
1. Гость видит меню с фото до прихода: меньше вопросов в WhatsApp и директ.
2. Предзаказ на вынос: заказ прилетает бариста в Telegram, гость забирает без очереди.
3. Лояльность «каждый 6-й кофе бесплатно» в приложении вместо картонной карточки: гости возвращаются.

**Кто пользователь.**
- Гость: открыл бота, выбрал напиток, указал время, нажал «Заказать».
- Бариста / владелец: получает заказ сообщением в Telegram-группу кофейни.

**Что такое успех для демо.** Владелец за 60 секунд на своём телефоне проходит путь «открыл → выбрал → заказал», и заказ приходит в Telegram на глазах у него.

## Scope демо (v0)

Входит:
- Экран «Меню»: категории (кофе, авторские напитки, холодные, десерты), карточки с фото, названием, ценой, кнопкой «+».
- Корзина: состав, сумма, выбор времени самовывоза (ближайшие слоты по 15 минут в рабочие часы), имя гостя (из Telegram), комментарий.
- Оформление: заказ сохраняется в БД, бот шлёт сообщение в чат кофейни и подтверждение гостю.
- Экран «Мои штампы»: 6 кружков, заполненные по числу заказов, «Следующий кофе бесплатно» при 5.
- Данные меню: 10–12 позиций, фото с карточки 2ГИС кофейни (только для показа владельцу, удалить, если не договоримся).

Не входит (v1, после договорённости):
- Оплата в приложении.
- Админ-панель (редактирование меню, статусы заказов).
- Доставка, столики, несколько точек.
- Пуш-напоминания.

## Tech Stack

- Frontend: React 18 + Vite + TypeScript, `@twa-dev/sdk` (Telegram Web App). Стили: CSS-модули, без UI-библиотек.
- Backend: Node.js 20 + Express + TypeScript, `better-sqlite3`, `grammy` (Telegram Bot API).
- БД: SQLite (файл), схема через миграцию в коде. Переезд на PostgreSQL при v1.
- Хостинг демо: фронт Vercel, бэк Railway (оба бесплатные тарифы). Бот создаётся через @BotFather.

## Code Style

TypeScript strict, функции маленькие, имена по-английски, комментарии по-русски там, где неочевидно.

```ts
// apps/api/src/lib/slots.ts
export function pickupSlots(now: Date, open: string, close: string, stepMin = 15): string[] {
  const [oh, om] = open.split(':').map(Number)
  const [ch, cm] = close.split(':').map(Number)
  const start = new Date(now)
  start.setMinutes(Math.ceil((now.getMinutes() + 10) / stepMin) * stepMin, 0, 0)
  const end = new Date(now); end.setHours(ch, cm, 0, 0)
  const first = new Date(now); first.setHours(oh, om, 0, 0)
  const cursor = start < first ? first : start
  const out: string[] = []
  for (let t = cursor; t <= end; t = new Date(t.getTime() + stepMin * 60_000)) {
    out.push(t.toTimeString().slice(0, 5))
  }
  return out
}
```

Правила: цены в рублях целым числом (в меню нет копеек), форматирование только в UI; никаких секретов в коде, токен бота через `.env`; каждый экран отдельный файл.

## Testing Strategy

- Unit (Vitest): генерация слотов самовывоза, подсчёт штампов лояльности, валидация заказа (пустая корзина, время вне рабочих часов).
- Интеграция: `POST /api/orders` сохраняет заказ и вызывает отправку в бот (бот замокан).
- Ручная проверка: открыть мини-апп в Telegram на iPhone и Android, пройти заказ, увидеть сообщение в чате.
- Порог для демо: все unit-тесты зелёные, ручной прогон пройден.

## Boundaries

- Всегда: тесты перед коммитом; цены и меню только из `menu.json`, не хардкодить в компонентах; фото кофейни использовать только для показа владельцу.
- Спросить сначала: добавление зависимостей сверх списка, изменение схемы БД, любая оплата, публикация бота на широкую аудиторию.
- Никогда: коммитить `.env` и токены; выдавать демо за готовый продукт; обещать владельцу цифры продаж.

## Success Criteria

1. Мини-апп открывается из бота на телефоне, меню с фото грузится за 2 секунды на LTE.
2. Заказ из 2 позиций с выбором времени оформляется за 4 нажатия.
3. Сообщение о заказе приходит в Telegram-чат кофейни в течение 3 секунд: имя, состав, сумма, время самовывоза.
4. Экран лояльности показывает верное число штампов после 1, 5 и 6 заказов.
5. Unit-тесты слотов и лояльности проходят.
